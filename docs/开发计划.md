# YCFMG 开发计划

> 版本节奏：`fmg<YY><MM>.<NNN>`，如 `fmg2609.010`

## 里程碑

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| M0 | 仓库骨架、配置、日志、SQLite 数据层、YAML 解析器 | 已完成 |
| M1 | 图像能力：感知哈希、颜色直方图、EXIF、规则分类、缩略图 | 已完成 |
| M2 | 索引器：增量扫描、按需索引、定时任务、丢失标记 | 已完成 |
| M3 | 文件管理 API：浏览、新建、重命名、移动、复制、删除、回收站、上传 | 已完成 |
| M4 | 检索：以图搜图、以文搜图、重复聚合、语义增强适配器 | 已完成 |
| M5 | 分享：多域名绑定、专属分享页、密码、有效期、访问统计 | 已完成 |
| M6 | 前端：Windows 风格资源管理器 + 图库视图 + 设置 | 已完成 |
| M7 | 打包：Docker、fpk、多平台二进制、部署脚本 | 已完成 |
| M8 | 增强：人脸聚类、视频抽帧、OCR 文字检索、地图视图 | 规划中 |
| M9 | 增强：多用户与权限组、目录级分享权限、WebDAV 挂载 | 规划中 |

## 本版本（fmg2609.010）交付范围

### 文件管理
- [x] 目录浏览（面包屑、地址栏、前进后退、上级、刷新）
- [x] 四种视图：大图标、平铺列表、详细信息（可排序表头）
- [x] 多选：单击 / Ctrl 点选 / Shift 连选 / 全选 / 框选空白取消
- [x] 右键上下文菜单、键盘快捷键（Ctrl+A/C/X/V、F2、Del、Enter）
- [x] 真实文件操作：新建、重命名、移动、复制、删除（回收站）、恢复、彻底删除
- [x] 上传：多文件、文件夹（保留相对路径）、拖拽到窗口
- [x] 只读模式（全局开关 + 单库开关）

### 图库
- [x] 时间线瀑布流，按日分组，自动排版
- [x] 分类、色调、收藏维度筛选
- [x] EXIF 元数据：拍摄时间、相机、镜头、光圈、快门、ISO、焦段、GPS
- [x] 自动标签：分类、画幅、分辨率档位、色调、亮度、对比、清晰度、相机机型
- [x] 相似聚合与重复图检测

### 检索
- [x] 以图搜图（上传、拖拽、库内图片一键以图搜图）
- [x] 以文搜图（中文分词 + 同义词扩展 + 字段加权）
- [x] 关键词建议（分类、标签、相机、色系）
- [x] 可选语义向量检索（OpenAI 兼容端点）

### 分享
- [x] 单文件 / 多文件 / 文件夹分享
- [x] 专属分享页：封面、瀑布流、灯箱、打包下载
- [x] 提取密码、有效期、下载次数上限、禁止下载
- [x] 多域名绑定，链接随访问域名自动切换
- [x] 访问统计（PV、下载次数、最近访问与来源 IP）

### 部署
- [x] Docker 多架构镜像（amd64 / arm64）
- [x] fpk 安装包（飞牛 NAS）
- [x] Linux 静态二进制 + systemd 单元
- [x] 一键构建、推送、部署脚本

## 验收标准（本版本）

| 项 | 标准 | 验证方式 |
| --- | --- | --- |
| 启动 | `ycfmg --version` 输出 `fmg2609.010` | 命令行 |
| 浏览 | 列出任意受管目录，含目录文件数/图片数 | `GET /api/fs/list` |
| 索引 | 5 张测试图全部入库，分类与标签正确 | `GET /api/gallery/facets` |
| 以图搜图 | 相同图片相似度 100%，标记「疑似重复」 | `POST /api/search/image` |
| 以文搜图 | 搜索「风景」命中风景类图片 | `GET /api/search?q=风景` |
| 缩略图 | 生成 256/768 两档 JPEG 缓存 | `GET /api/thumb` |
| 分享 | 分享页可打开，zip 打包正确，多域名链接齐全 | `GET /s/{token}` |
| 权限 | 未登录访问受保护接口返回 401 | `GET /api/fs/list` |
| 安全 | 越界路径被拒绝 | `GET /api/fs/list?path=/etc` |

## 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 大图库索引耗时长 | 首次体验差 | 增量索引 + 按需索引 + 后台任务可见进度 |
| 规则分类误判 | 分类不准 | 分类结果可读可覆盖，支持手动标签与备注 |
| 感知哈希对旋转/裁剪鲁棒性有限 | 相似召回不全 | 与颜色直方图融合；后续可接 CLIP 端点补强 |
| 大量缩略图占空间 | 磁盘压力 | 可一键清理缓存；缓存键含 mtime，源变更自动失效 |
