# YCFMG 部署指南

## 一、Docker Compose（推荐）

```bash
mkdir -p /vol1/1000/ycfmg && cd /vol1/1000/ycfmg
curl -O https://raw.githubusercontent.com/YCyingchen/YCFMG/main/docker/docker-compose.yml
docker compose up -d          # 启动
docker compose logs -f        # 看日志
docker compose down           # 停止
```

compose 文件内容（按需修改端口与目录）：

```yaml
# YCFMG 文件管理 + 智能图库（Docker Compose）
# 用法：docker compose up -d
services:
  ycfmg:
    image: ycyingchen/ycfmg:fmg2609.003   # 镜像，支持 amd64 / arm64
    container_name: ycfmg                 # 容器名
    restart: unless-stopped               # 开机自启
    ports:
      - "8686:8686"                       # 左边可改成别的端口，如 "9000:8686"
    environment:
      TZ: Asia/Shanghai                   # 时区
      YCFMG_ADMIN_PASSWORD: "改成你的密码"  # 管理员密码（首次启动生效）
      # 多域名：访问者用哪个域名进来，分享链接就用哪个域名生成
      YCFMG_PUBLIC_URLS: "http://127.0.0.1:8686"
      # 在线更新检查用的代理，不需要可留空或删除
      YCFMG_UPDATE_PROXY: "http://127.0.0.1:7890"
    volumes:
      - ./config:/config                  # 配置与数据库，务必保留
      - /vol1/1000:/data                  # 要管理的目录，可挂多个
      # - /vol5/1000/空间4:/media         再加一个目录就复制这一行
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://127.0.0.1:8686/api/health"]
      interval: 30s
      timeout: 5s
      retries: 3
```

启动后访问 `http://设备IP:8686`，账号 `admin`，密码为 `YCFMG_ADMIN_PASSWORD`。
若要再加一个目录，复制一行 `- /vol5/1000/空间4:/media` 即可。
## 二、飞牛 NAS（fpk）

1. 生成安装包：

```bash
bash scripts/build-fpk.sh
# 产出 dist/YCFMG_fmg2609.003.fpk
```

2. 在飞牛 NAS 的「应用中心 → 手动安装」中选择该 fpk 文件。
3. 安装后应用数据位于安装目录的 `data/`，配置位于 `etc/config.yaml`。

fpk 内部结构：

```
YCFMG_fmg2609.003.fpk
├── manifest            应用元信息（名称、版本、端口、平台）
├── ICON.PNG            128×128 图标
├── ICON_256.PNG        256×256 图标
├── app.tgz             应用本体（bin/ycfmg、etc/config.example.yaml）
└── cmd/                生命周期脚本
    ├── main            start / stop / restart / status
    ├── install_callback
    ├── upgrade_callback
    ├── uninstall_callback
    └── config_callback
```

> 若本机装有飞牛官方 `fnpack`，也可用它重新打包以获得官方签名校验。

## 三、二进制 + systemd

```bash
# 1. 构建
TARGETS="linux/amd64" bash scripts/build.sh

# 2. 部署
sudo mkdir -p /opt/ycfmg/{bin,etc,data}
sudo cp dist/ycfmg-linux-amd64 /opt/ycfmg/bin/ycfmg
sudo cp configs/config.example.yaml /opt/ycfmg/etc/config.yaml
sudo chmod +x /opt/ycfmg/bin/ycfmg

# 3. 服务单元
sudo tee /etc/systemd/system/ycfmg.service >/dev/null <<UNIT
[Unit]
Description=YCFMG File Manager and Gallery
After=network.target

[Service]
Type=simple
ExecStart=/opt/ycfmg/bin/ycfmg --config /opt/ycfmg/etc/config.yaml --data /opt/ycfmg/data
Restart=always
RestartSec=5
Environment=TZ=Asia/Shanghai

[Install]
WantedBy=multi-user.target
UNIT

sudo systemctl daemon-reload && sudo systemctl enable --now ycfmg
sudo systemctl status ycfmg
```

## 四、远程一键部署

编辑 `scripts/deploy.env`（该文件已被 .gitignore 忽略）：

```bash
FNOS_HOST="127.0.0.1"
FNOS_USER="root"
FNOS_PASS="你的密码"
FNOS_DEST="/opt/ycfmg"
FNOS_PORT="8686"
```

然后执行：

```bash
source scripts/deploy.env && bash scripts/deploy-fnos.sh
```

脚本会构建 amd64 二进制、上传、写入 systemd 单元并启动服务。

## 五、配置文件

配置优先级：内置默认 < 配置文件 < 环境变量。

关键项：

| 配置项 | 环境变量 | 说明 |
| --- | --- | --- |
| `server.port` | `YCFMG_PORT` | 监听端口，默认 8686 |
| `server.public_urls` | `YCFMG_PUBLIC_URLS` | 多域名绑定，逗号分隔，首个为首选域名 |
| `server.base_path` | `YCFMG_BASE_PATH` | 反向代理子路径 |
| `server.trust_proxy` | - | 是否信任 `X-Forwarded-*` 头 |
| `server.readonly` | `YCFMG_READONLY=1` | 全局只读模式 |
| `data_dir` | `YCFMG_DATA_DIR` | 数据目录（数据库、缩略图、回收站） |
| `libraries[]` | `YCFMG_LIBRARIES` | 文件库；`路径:ro` 表示只读 |
| `auth.password` | `YCFMG_ADMIN_PASSWORD` | 首次启动的管理员密码 |
| `index.scan_interval_minutes` | - | 自动索引间隔 |
| `share.default_expire_days` | - | 分享默认有效期 |
| `semantic.*` | `YCFMG_SEMANTIC_ENDPOINT` | 可选的语义向量端点 |

## 六、多域名与反向代理

### 多域名

在「设置 → 域名绑定」中每行填写一个域名：

```
https://fm.example.com
https://nas.example.com
http://127.0.0.1:8686
```

第一个是首选域名。用户用哪个域名访问，复制出来的分享链接就用哪个域名；
`GET /api/shares/{id}/links` 会返回全部域名的链接。

### Nginx 反向代理示例

```nginx
server {
    listen 443 ssl http2;
    server_name fm.example.com;

    client_max_body_size 20G;

    location / {
        proxy_pass http://127.0.0.1:8686;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Host $host;
        proxy_http_version 1.1;
        proxy_read_timeout 3600s;
    }
}
```

子路径部署时设置 `server.base_path: /files`，并把 `location / {` 改为 `location /files/ {`。

## 七、备份与迁移

需要备份的只有 `data_dir`（数据库、回收站、缩略图）与配置文件。
文件库本身是用户的原始文件，YCFMG 从不修改未通过界面操作的内容。

迁移到新机器时，恢复 `config.yaml` 与 `data_dir` 后启动即可；若文件库路径变化，
修改配置中的 `libraries`，然后触发一次索引。

## 八、常见问题

**Q：图片没有出现在图库里？**
确认该目录属于某个 `libraries` 条目，然后在「设置 → 索引与缓存」中点击「立即全量索引」。

**Q：以文搜图搜不到想要的图？**
默认检索依赖文件名、目录、标签与分类。可通过给图片打标签提升命中率；
配置 `semantic.endpoint` 后可启用向量语义检索。

**Q：缩略图占空间太大？**
「设置 → 清理缩略图缓存」可一键清空，之后按需重新生成；也可调小 `index.thumb_sizes`。

**Q：如何限制只读？**
全局只读设置 `server.readonly: true`；单库只读在对应 `libraries` 条目加 `readonly: true`。
