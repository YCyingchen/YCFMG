飞牛 fnOS 安装

该应用包符合飞牛开发者规范（manifest / cmd 生命周期脚本 / config 权限与资源声明 / wizard），安装后由应用中心统一管理启停与升级。
  1. 下载 YCFMG_fmg2609.001.fpk；
  2. 打开飞牛 NAS →「应用中心」→「手动安装」，选择该 fpk 文件；
  3. 安装完成后在应用中心启动，浏览器访问 http://设备IP:8686；
  4. 首次登录使用 admin，初始密码在应用日志（应用中心 → 日志，或 应用数据目录/info.log）中查看，并请立即修改。

Docker 部署

新建一个目录，放入 `docker-compose.yml`，然后执行 `docker compose up -d`。

services:  ycfmg:    image: ycyingchen/ycfmg:fmg2609.001    container_name: ycfmg    restart: unless-stopped    ports:      - "8686:8686"    environment:      TZ: Asia/Shanghai      YCFMG_ADMIN_PASSWORD: "改成你的密码"      YCFMG_PUBLIC_URLS: "http://192.168.1.8:8686"    volumes:      - ./config:/config      - /vol1/1000:/data

启动后访问 `http://设备IP:8686`，账号 `admin`，密码为上面填写的值。

应用内在线更新

在应用「设置 → 在线更新」可一键检查新版本，检查顺序为：官方下载站 version.json、GitHub Release、Docker Hub 标签。

GitHub 与 Docker Hub 在境内通常需要代理，可在同一面板填写，例如 http://192.168.1.8:7890，也可用环境变量 YCFMG_UPDATE_PROXY 配置。
