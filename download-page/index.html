用文件管理器的自由度，配图库的检索体验。真实目录零搬迁，以图搜图、以文搜图、自动分类标签，专属分享页与多域名绑定。

下载安装

YCFMG 飞牛应用包

在飞牛 NAS 的「应用中心 → 手动安装」中选择该文件，安装向导里填好账号密码即可。

下载 fpk（{{SIZE_FPK}}）
  1. 下载上方的 .fpk 文件；
  2. 飞牛 NAS →「应用中心」→「手动安装」→ 选择该文件；
  3. 安装向导中填写管理员账号、密码、服务端口；
  4. 安装完成后在应用中心点击图标即可在桌面窗口内打开，默认端口 8686。

功能特性

文件管理

  • 导航窗格 + 面包屑 + 命令栏 + 详细信息面板
  • 大图标 / 平铺 / 列表 / 详细信息 四种视图
  • 多选、右键菜单、快捷键、拖拽移动
  • 上传（含文件夹）、回收站与恢复

智能图库

  • 时间线瀑布流，按日分组
  • EXIF：拍摄时间、相机、镜头、GPS
  • 自动分类与标签，可按分类 / 色调筛选
  • 重复图检测

以图搜图 / 以文搜图

  • 感知哈希 + 颜色直方图，零模型依赖
  • 中文分词 + 同义词扩展 + 字段加权
  • 拖一张图进搜索框即可找相似

分享与多域名

  • 专属分享页，支持密码与有效期
  • 绑定多个域名，链接随访问域名自动切换
  • 访问统计与打包下载
